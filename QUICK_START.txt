ALLAHABAD HOUSE PRICE ML APP — QUICK START

1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open Terminal in VS Code.
4. Run:
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   streamlit run app.py
5. Upload the Allahabad housing CSV in the app sidebar.
6. Select Price as target (if that is the target in your dataset).
7. Choose house feature columns, train, inspect validation MAE, and try a prediction.

GitHub commands are in README.md.
